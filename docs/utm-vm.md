# Create an Ubuntu VM in UTM

[Download UTM](https://mac.getutm.app/) and install
it.

Then download Ubuntu Server 24.04 LTS from
<https://ubuntu.com/download/server/arm>.

1. Open UTM.
2. Click "Create a New Virtual Machine"
3. On "Start" screen, select "Virtualize"
4. On "Operating System" screen, select "Linux"
5. On "Linux" screen under "Boot ISO Image", click "Browse" and select the Ubuntu ISO file you've downloaded.
6. On the next couple of screens:
  - Set memory to 2048 MiB 
  - Set storage to 20 GiB
7. On "Shared Directory" screen, just click "Continue"
8. On "Summary" screen you can give your VM another name if you want, otherwise just "Save"

Click the big play button to start it.

Next, [Install Ubuntu Server](./install-ubuntu.md).
