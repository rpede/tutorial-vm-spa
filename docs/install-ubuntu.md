# Install Ubuntu Server

1. Select "Try or Install Ubuntu Server"
2. Select "English" as language
3. Pick whatever keyboard layout you are accustomed to.
4. Choose "Ubuntu Server" as installation type.
5. Defaults for Network, Proxy, Mirror and Storage configuration.
  - Don't worry about "Confirm destructive action" as it is completely safe as you are running the installation in a VM
6. For Profile configuration, type a username and password you can remember and give it a hostname.
7. Skip "Upgrade to Ubuntu Pro"
8. Check `[x]` to "Install OpenSSH server"
9. Don't select any "Featured server snaps"
10. Wait until it says "Installation complete!", then "Reboot Now".
11. After reboot, select "Boot from next volume" from boot menu.
12. When you see "login" on the screen enter the username and password you chose.
12. Take note of the IPv4 address shown, since you'll need it for later.

Congrats! You now got yourself a VM running Ubuntu Server.

Navigate back to the main guide and continue.
